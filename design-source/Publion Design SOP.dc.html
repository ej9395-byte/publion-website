1. 원칙

책 표지가 화면에서 가장 강한 색이어야 합니다. 인터페이스는 흰 바탕, 검정 활자, 얇은 괘선으로만 이루어지고, 강조색은 한 가지만 씁니다. 표지가 들어오면 인터페이스는 뒤로 물러납니다.

여백이 구분선입니다. 박스를 그리거나 배경을 깔아 영역을 나누지 않고, 섹션 사이 1px 괘선과 넉넉한 상하 여백으로 나눕니다.

2. 색

값 이름 쓰는 곳
{{ c.hex }} {{ c.name }} {{ c.use }}

강조색 #9E2B1F는 분류 라벨, 활성 상태, 링크 hover에만 씁니다. 버튼 바탕이나 큰 면적에는 쓰지 않습니다. 새 색을 추가하지 않습니다.

3. 서체

두 벌만 씁니다. Noto Sans KR(300·400·500·700)은 제목과 도서명, Archivo(400·500·600)는 그 외 전부. 영문 부제는 Archivo 이탤릭.

한글 폴백은 Apple SD Gothic Neo → Malgun Gothic 순입니다. 구글 폰트가 뜨지 않아도 같은 계열로 떨어집니다.

용도 서체 / 굵기 크기 · 자간 · 행간
{{ t.use }} {{ t.face }} {{ t.spec }}

라벨류(분류·날짜·버튼·내비)는 전부 대문자 + 넓은 자간입니다. 본문에는 대문자 변형을 쓰지 않습니다.

고딕으로 바꾸면서 지켜야 할 두 가지
큰 제목에 자간 -0.02em. 고딕은 명조보다 획이 굵어 보여 46px 이상에서 글자가 서로 밀어냅니다. 히어로·페이지 제목·도서 상세 제목에 적용합니다. 30px 섹션 제목에는 넣지 않습니다.

이탤릭에는 합성 차단. Noto Sans KR에는 이탤릭 자획이 없어서 font-style:italic만 걸면 브라우저가 한글을 억지로 기울입니다. 이탤릭을 쓰는 자리마다 font-synthesis-style:none을 함께 넣어, 영문만 기울고 한글은 곧게 서게 합니다.

한글 제목에는 자간을 넓히지 않습니다. 좁히는 것만 위 규칙대로 씁니다.

4. 레이아웃

  • 좌우 여백 32px. 풀블리드 섹션(히어로·피처·프로모)만 예외.
  • 일반 섹션 상하 여백 78px, 섹션 사이 1px #E2E2DE 괘선.
  • 히어로 배너 높이 620px 고정.
  • 2단 섹션의 각 칸에 min-width:0, 그리드 트랙에 minmax() 하한. 이미지가 칸을 밀어내는 것을 막습니다.
  • 이미지 칸 높이는 aspect-ratio로 정합니다. min-height로 잡지 않습니다.
  • 모든 반복 배치는 flex/grid + gap. 여백을 요소별 margin으로 만들지 않습니다.

7. 이미지

모든 이미지 자리는 드래그앤드롭 슬롯입니다. 슬롯마다 고유 ID가 있고, 같은 ID는 같은 이미지를 공유합니다. 표지를 한 번 넣으면 홈·목록·상세·관련도서에 모두 반영됩니다.

ID 형식 맞춤 내용
{{ s.id }} {{ s.fit }} {{ s.what }}

표지는 contain(잘리지 않게), 배너·타일은 cover(꽉 차게). 표지 원본은 배경 없는 정면 이미지로, 짧은 변 1200px 이상 권장.

8. 글쓰기

  • 제목은 한글 + 영문 병기. 형식은 도서 Books처럼 한글 뒤에 영문, 영문은 회색.
  • 분류 라벨은 경제경영 Business 형식으로 통일.
  • 책 소개는 서점 상세페이지 문안을 그대로 옮기지 않습니다. 홈페이지용으로 다시 씁니다.
  • 사실만 씁니다. 수상·선정·판매 실적은 확인된 것만.
  • 느낌표, 이모지, 감탄사를 쓰지 않습니다.

9. 신간 추가 절차

  1. 도서 데이터에 항목 추가 — 제목, 부제, 지은이, 옮긴이, 분야, 정가, 출간 연·월.
  2. 표지 슬롯 cover-{번호}에 표지 이미지를 끌어다 놓기.
  3. 신간 5단은 출간일 기준 자동 정렬이므로 별도 작업 없음.
  4. 히어로에 올릴 책이면 배너 이미지를 따로 준비(가로 긴 판형, 왼쪽 40%는 텍스트가 덮음).
  5. 분야가 새로 생기면 분야 타일이 4개를 넘지 않는지 확인. 넘으면 열 수를 조정.
